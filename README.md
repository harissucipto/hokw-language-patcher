# HoKW Language Patcher

Aplikasi Android untuk memasang **Bahasa Indonesia** ke game Honor of Kings World (王者荣耀世界)
langsung di HP, tanpa komputer. Semua terjemahan sudah ada di dalam aplikasi. Tombol **Kembalikan
ke asli** mengembalikan game ke bahasa Cina persis seperti semula.

**Unduh versi terbaru:**
https://github.com/harissucipto/hokw-language-patcher/releases/latest/download/HoKW-Language-Patcher.apk

## Baca dulu: risiko akun

Mengubah data game melanggar ketentuan layanan game, dan akun bisa dikenai sanksi. Perubahannya
tetap bisa dideteksi; tidak ada yang disembunyikan. Pakai **akun uji**, bukan akun utama. Risikonya
Anda tanggung sendiri.

## Yang dibutuhkan

- HP Android 11 atau lebih baru (HP keluaran 2019 ke atas umumnya bisa).
- Game Honor of Kings World sudah terpasang dan unduhan di dalam game sudah selesai sampai layar
  login.
- Aplikasi **Shizuku** (gratis di Play Store). Aplikasi ini memandu cara memasang dan menyalakannya,
  tanpa root dan tanpa komputer.
- Ruang kosong sekitar 150 MB.

## Cara pakai

1. Unduh APK dari tautan di atas, buka berkasnya, izinkan pemasangan dari sumber tidak dikenal, pasang.
2. Buka **HoKW Language Patcher**. Kartu paling atas selalu memberi tahu langkah berikutnya dan satu
   tombol untuk melakukannya: siapkan Shizuku → nyalakan Shizuku → beri izin → **Pasang Bahasa
   Indonesia**.
3. Tutup game dulu, lalu tekan **Pasang Bahasa Indonesia**. Tunggu 2–3 menit; bar progres akan diam
   sebentar di tengah, itu normal.
4. Tekan **Buka game**. Menu, nama skill, dan quest tampil dalam Bahasa Indonesia. Sebagian teks yang
   datang dari server (pengumuman, event) tetap Cina.

Layar **Panduan** di dalam aplikasi menjelaskan semua langkah dengan gambar, termasuk bagian
"Kalau gagal".

## Pembaruan

Aplikasi memberi tahu bila ada versi baru (tombol **Cek pembaruan**). Pasang APK baru di atas yang
lama tanpa uninstall, lalu tekan **Pasang Bahasa Indonesia** lagi.

Setelah game update, bahasanya biasanya kembali Cina. Buka aplikasi dan tekan **Pasang Bahasa
Indonesia** lagi.

Sebelum menghapus aplikasi, tekan **Kembalikan ke asli** dulu supaya game kembali ke bahasa aslinya.

## Kalau ada masalah

- **Game masih terbuka**: tutup game dari daftar aplikasi terbaru, tunggu sebentar, coba lagi.
- **Unduhan game belum selesai**: buka game sampai layar login tanpa bar unduhan, tutup, coba lagi.
- **Shizuku belum berjalan**: Shizuku mati setiap HP di-restart. Buka Shizuku, nyalakan lagi, lalu
  tekan **Hubungkan Shizuku** di aplikasi.
- **Teks masih Cina setelah dipasang**: kalau game baru update, tekan Pasang lagi. Teks pengumuman
  dan event memang dari server dan tidak bisa diterjemahkan oleh aplikasi ini.
- Pertanyaan lain: lewat **Issues** di halaman ini, sebutkan versi aplikasi dan versi Android Anda,
  tanpa data akun.
